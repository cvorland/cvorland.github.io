Authoring and Management of Transparent Research Integrity Assessments of Randomised Clinical Trial Publications Using LLM-Assisted Tools and Provenance Knowledge Graphs

Milan Markovic; Goutham Indukuri; Somayajulu Sripada; Colby J. Vorland; Jack Wilkinson; Clare Robertson; Mark Bolland; Andrew Grey; Miriam Brazzelli; Alison Avenell

Describes LLM-assisted tools and provenance records for producing transparent research-integrity assessments of clinical trials.

Resource verification & source notes
  • Preprint: Public preprint record in the saved source catalogue. No final journal article identified as of retrieval.
  • RIPE-KG assessment data (version 1.0.0): The manuscript links RIPE-KG and describes 140 assessments. Retrieved version 1.0.0 assessments/assessments.json parses to 140 assessment records and 15 reviewer records, matching the described release; repository inventory and README confirm public assessment export. Current main contains a later 1.1.0 dataset, so this link selects the manuscript-associated snapshot.
  • INSPECT-AI source code (version 1.0.0): The manuscript explicitly links INSPECT-AI version 1.0.0 LLM_GUIDE.md. The complete tagged tree contains the API, UI and assessment engine; LLM guide and packages/python/core/checks/retraction_detection.py retrieved and inspected as text without executing downloaded code.
  • RIPE-O ontology (version 1.0.0): The manuscript explicitly identifies RIPE-O as its ontology resource. Retrieved release/1.0.0/ontology.ttl declares the RIPE-O ontology, version 1.0.0 URI and CC BY 4.0 license.
